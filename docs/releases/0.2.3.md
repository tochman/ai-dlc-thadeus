## Prioritisation by user value

The order is user value first, cost second. Declared priority alone would put US-0506 on top; it is placed second in the sequence because it is High complexity and needs US-0803 underneath it.

1. **US-0506** — the only unstarted High-priority story. It closes the largest remaining gap: the popup sees AI-DLC's audit questions only, so a permission prompt or a free-text reply from the agent still sends the person back to the terminal. Highest daily value; High complexity; needs US-0803.
2. **US-0405** — the settings view that the other stories point at: language (EPIC-07), harness per project, tool paths, default project folder. It also removes a real dead end — an `aidlc` or `claude` the app cannot find has no fix in the UI today.
3. **US-0904** — models and effort per agent with the cost of the choice beside it. The payoff of EPIC-02 and US-0901: answering "is the reviewer really on the cheaper model?" and being able to act on it.
4. **US-0902** — turns the read-only configuration view from v0.2.2 into something the person can change: project defaults, and the active work's depth, test strategy and guard policy.
5. **US-0407** — staying current without hunting for the DMG. Low effort per unit of ongoing value, and it pays back on every release.
6. **US-0903** — custom plans: high value for whoever repeats the same kind of work, less for one-off shapes of work.
7. **US-0803** — narrow audience (people who use both Claude Code and opencode), cheap, and it is the gate for US-0506.
8. **US-0504** — overlaps conceptually with US-0407 (app updates versus framework updates); occasional rather than daily.
9. **US-1001** — a big win for someone who lives in the app, but High complexity and it overturns the read-only rule, so it needs a release with room for the conflict and save handling.
10. **US-0702** — Low priority by declaration and the smallest audience today; grows in value once there is a community to translate.

## The v0.2.3 slice

Four stories, all Medium/Medium, none blocked. Build order:

1. **US-0405 Settings view with native file pickers** — first, because it becomes the home that US-0902, US-0904 and US-0702 later hang off, which makes the following stories cheaper.
2. **US-0902 Change project defaults and the active work's settings** — the write half of the configuration view.
3. **US-0904 Choose models and effort per agent** — the cost-control story, on the same preview-then-apply machinery as US-0902.
4. **US-0407 Update the app from a GitHub release** — independent of the three above; ships in parallel and makes v0.2.3 the first release that can deliver itself.

**Stretch, if there is room:**

- **US-0803** (preferred) — small, and it sets up v0.2.4's headline.
- **US-0903** — plans, only with clear capacity left.

**Deliberately not in v0.2.3:** US-0506 (needs US-0803 and a release of its own), US-1001, US-0702, US-0504.
