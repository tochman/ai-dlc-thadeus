## Build order

1. **US-0006 Popup answers reach Claude Code's real picker** — first, because it hurts every day: US-0004 shipped in v0.2.3, but answers from the popup still don't land. The cause is found in a real Claude Code session before the fix.
2. **US-0409 The About window in the new LCARS design** — small and visual; changes only the look of US-0408's window.
3. **US-0207 Live token view while the work runs** — small and visual; reads the same ledger as US-0205's live cost, with no new watcher.
4. **US-0903 Create and reuse custom plans** — all of it, tier-2 edit and delete included, in its own view from the left arm.
5. **US-1001 Edit files in the app with Monaco** — last, because it is the largest and the first to break the read-only rule. Its save and conflict handling is not cut. If the slice turns out too large, it is the first story to move.

**Deliberately not in v0.2.4:** US-0205 (named by mistake; it shipped in v0.2.0), US-0506 (questions from Claude Code and opencode in a dialog), US-0504 (framework updates), US-0702 (own translation files). `0.2.3.md` listed US-0506 and US-0504 for v0.2.4; the person did not name them for this release.
