**Working rules:** each story has its own branch and pull request, without the deployment stages; the release is its own workflow. When two stories are open at once, `main` is merged into the later branch and the whole suite is run again before its Build and Test is approved.

## Checked before the start (2026-11-25)

- **US-0513.** AI-DLC 2.11.3's archive works on running and complete intents, also ones that are not active, in the active space only. It clears the active intent when that is the one archived, and refuses a blank reason, an intent with no row in `intents.json`, and claimed team Units. Read from its source; tried for real 2026-11-25: the command is `aidlc engine intent archive`, not `aidlc intent archive`. Unarchiving always brings an unfinished intent back as `Running`.
- **US-0804.** `gh auth status`, `claude auth status` (JSON with `loggedIn`) and `opencode auth list` all exist. `opencode auth export` and `gh auth status --show-token` print secrets and are never run.
