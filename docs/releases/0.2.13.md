# Release plan v0.2.13

> Release plans list the stories a release takes from several epics. The epics stay organised by topic; status lives in [FEATURES.md](../FEATURES.md) and in each epic file.
>
> Previous release: v0.2.12 (the Linux update installs again).

**Theme:** Smoother daily use. The app always finds Claude Code, shows `main`'s releases on a story branch and keeps its own files in sync with `main`, parks and unparks an intent, and folds the list column away to give the main view room. The README is rewritten to show it all.

**Scope change (2026-11-20):** US-0609 moved here from v0.3.1 at the person's request. US-1103 added the same day.

## Build order

| # | Story | AI-DLC plan | Why here |
|---|-------|-------------|----------|
| 1 | **US-0035** Agent CLIs found | quick-fix | Without it the agent tabs can fail to start until the app is restarted. |
| 2 | **US-0036** Main's releases on a branch | quick-fix | A release added on `main` is invisible while a story branch is checked out. |
| 3 | **US-0609** App files in sync with `main` | ultra-express | Builds on US-0036: the same planning sync, extended to the app's own files and harness settings. |
| 4 | **US-0510** Park and unpark | ultra-express | Resuming a parked intent stops at a command the person must type first. |
| 5 | **US-0415** Collapse the list | ultra-express | Wide views (the Unit graph) are cut off beside the list. |
| 6 | **US-1103** README rewrite | docs, no workflow | Last, so its screenshots and features include everything else in this release. |
