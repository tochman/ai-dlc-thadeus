# Release plan v0.2.13

> Release plans list the stories a release takes from several epics. The epics stay organised by topic; status lives in [FEATURES.md](../FEATURES.md) and in each epic file.
>
> Previous release: v0.2.12 (the Linux update installs again).

**Theme:** Smoother daily use. The app always finds Claude Code, an intent can be parked and unparked from the app, and the list column folds away to give the main view room.

---

## The v0.2.13 slice

Three stories, each in its own pull request into `main`. The release pull request carries the version bump.

| Story | Epic | Title | Priority | Complexity | Depends on | Status |
|-------|------|-------|----------|------------|------------|--------|
| US-0035 | [00](../features/epic-00-fixes.md) | The app finds the agent CLIs even when the login shell is slow to start | High | Small | US-0405 ✅, US-0410 ✅ | 📋 Planned |
| US-0510 | [05](../features/epic-05-workflow-control.md) | Park and unpark an intent from the app | Medium | Small | US-0501 ✅ | 📋 Planned |
| US-0415 | [04](../features/epic-04-branding-and-desktop.md) | Collapse the list column so the main view gets the room | Medium | Small | US-0414 ✅ | 📋 Planned |

## Build order

| # | Story | AI-DLC plan | Why here |
|---|-------|-------------|----------|
| 1 | **US-0035** Agent CLIs found | quick-fix | Without it the agent tabs can fail to start until the app is restarted. |
| 2 | **US-0510** Park and unpark | ultra-express | Resuming a parked intent stops at a command the person must type first. |
| 3 | **US-0415** Collapse the list | ultra-express | Wide views (the Unit graph) are cut off beside the list. |
