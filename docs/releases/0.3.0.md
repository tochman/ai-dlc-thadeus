# Release plan v0.3.0

> Release plans list the stories a release takes from several epics. The epics stay organised by topic; status lives in [FEATURES.md](../FEATURES.md) and in each epic file.
>
> Previous release: v0.2.11 (one committer per feature-doc change, and commit subjects that name only the stories that changed).

**Theme:** Spec Kit as an alternative to AI-DLC: the app sees which framework a project has, lets the person choose or switch, and follows and drives Spec Kit projects with their own views. A larger addition, so a minor version; the product is not ready for 1.0.

**Baseline (2026-11-19):** Moved here from v0.2.11 at the person's request, after the EPIC-14 Ideation check (intent `261119-spec-kit-ideation`). Nothing in it is built. Today the app opens only folders with `aidlc/spaces/` (`detectProject` in `src/main/projectService.js`). Supports Spec Kit v1.4.x and newer: tested on v1.4.x, newer versions read with a warning.

## Build order: value first

The order gets the person who asked for Spec Kit to a new Spec Kit project as soon as possible (EPIC-14 Ideation, scope definition).

| # | Stories | Why here |
|---|---------|----------|
| 1 | **US-1401**, **US-1408** | A Spec Kit project opens, and its framework is known on every clone. AI-DLC projects behave exactly as today. |
| 2 | **US-1405**, **US-1406** | Set up and choose: a new project can start on Spec Kit. |
| 3 | **US-1403** | The first feature is started from the app. The first-version measure is met here. |
| 4 | **US-1402**, **US-1410** | See the feature, its tasks and what the agent waits on. Starts with a test project made with `specify init`, which becomes the fixture for the rest. |
| 5 | **US-1409**, **US-1404**, **US-1407** | Token use per feature, the rules, and switching. |
| 6 | **US-0043** | The cleaning pass with `/simplify`: 0 ESLint warnings. Last, because it touches the same files as the Spec Kit stories. |

**Until US-1406:** the app follows what it finds. A folder with only `.specify/` opens as Spec Kit. A folder with both opens as AI-DLC, as today.

**Before step 4:** the `specify` CLI is installed on the build machine (`uv tool install specify-cli`), v1.4.x, and the version is noted in the fixture.

**Working rules for the release:** one story at a time, in this order; a fresh session after each stage; the full suite runs once before Build and Test is approved, and in CI.
