# Personas

## P1 — The developer answering the app's dialogs

- **Role:** runs Claude Code or opencode sessions through the dashboard and answers their questions, permission prompts, replies and compact / fresh-session offers in the agent dialog.
- **Goal:** what is on screen belongs to the moment they are in, so what they pick is the right answer to the right thing.
- **Pain point:** the dialog reopens on an old, already answered message, mostly over the compact / fresh-session offer, and does not close by itself when only answered pages are left (reported 2026-11-18).
- **Context:** often away in the terminal or another app; comes back when a new page opens the dialog.

There is one persona, so there is no priority ranking.
