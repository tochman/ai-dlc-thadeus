# Personas (US-0804)

## P1. Dana the developer (primary)
- **Role:** developer who works in THADEUS every day, with Claude Code or opencode in agent tabs and the GitHub views open.
- **Goals:** know that a sign-in has run out before an agent or a GitHub view fails on it; fix it without leaving the app.
- **Pain points:** an agent tab that stops at a sign-in screen; a GitHub view that fails with a reason that does not say what to do; a key in the shell's startup files that tools outside the shell do not see.
- **Tech comfort:** high. **Frequency:** daily; signs in now and then.

## P2. Nico the newcomer
- **Role:** developer who has just installed THADEUS and opens Settings before any project.
- **Goals:** get every tool ready; know which are signed in, and as whom.
- **Pain points:** does not know each tool's sign-in command; no project open yet, so no Shell tab.
- **Tech comfort:** medium. **Frequency:** once per machine.

**Priority:** P1 first. P2 meets the same rows, with no project open.
