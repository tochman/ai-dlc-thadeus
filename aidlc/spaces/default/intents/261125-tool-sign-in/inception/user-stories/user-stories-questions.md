# User Stories Plan (US-0804)

- **Personas:** two. The developer who works in the app every day, and the one who sets it up for the first time.
- **Format:** "As a [persona], I want [goal], so that [benefit]", following INVEST. Acceptance criteria are Given/When/Then, each with a stable `AC` ID and the requirement it comes from.
- **Priority:** MoSCoW. All Must Have: every story covers an acceptance criterion of US-0804.
- **Breakdown:** by workflow, six stories, built in order on one branch and one pull request as US-0804. The epic keeps US-0804 as its one story.

No questions: the five answers in Requirements Analysis and the approved requirements settle the choices. What the stories add is listed under Assumptions in `stories.md`.
