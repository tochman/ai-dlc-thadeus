# User Stories Plan (US-0513)

- **Personas:** two. The developer who tidies the list (primary), and the same or another developer in a second clone who pulls the result.
- **Format:** "As a [persona], I want [goal], so that [benefit]", following INVEST. Acceptance criteria are Given/When/Then, each with a stable `AC` ID and the requirement it comes from.
- **Priority:** MoSCoW. All Must Have: every story covers an acceptance criterion of US-0513, and archiving several with its commit is the reason it was asked for.
- **Breakdown:** by workflow, seven stories, built in order on one branch and one pull request as US-0513. The epic keeps US-0513 as its one story.

No questions: the four answers in Requirements Analysis and the approved requirements settle the choices. What the stories add is listed under Assumptions in `stories.md`.
