# Discovered Rules (final draft)

Stated by the person at the practices interview. The rules already affirmed in `aidlc/spaces/default/memory/project.md` are not repeated here.

## Mandated

ALWAYS write a failing test before the code for new behaviour (TDD).

ALWAYS keep line coverage at or above 80%, checked in CI.

ALWAYS run ESLint and Prettier in CI; a failure blocks the merge.

ALWAYS merge each story through its own squash-merged pull request; only docs and small chores may go straight to `main`.

## Forbidden

None.
