# Team Allocation: EPIC-14 Spec Kit

A **Bolt** is one build pass over a piece of the work, ending in something that runs. A **mob** is the group that builds a Bolt. Team Formation did not run in the classic plan, so every Bolt (U1–U10) is built by the developer agent (AI), and the person approves each plan and each checkpoint.

There is one team, so no program board is needed. The person is the sole decision-maker and does the hand checks before each release (`.dmg` and the smoke test).
